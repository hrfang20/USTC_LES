# 方法与阶段目标

[JHTDB SABL 数据集说明](https://turbulence.idies.jhu.edu/datasets/geophysicalTurbulence/sabl)给出 400 m 立方域、2048³ 网格、8 m/s 地转风和两种降温情形。底部采用粗糙面 MOST；SFS 使用预报动能及两部分模型。其水平谱方法用于参考平坦域，校园建筑需另行处理。

进一步阅读：[McWilliams et al. (2023)](https://doi.org/10.3390/atmos14071107)，[NCAR 作者版](https://www2.mmm.ucar.edu/people/patton/documents/mcwilliams_et_al.Atmos.2023.pdf)。精确初始温度、科里奥利参数、上边界、阻尼层及输出时间定义，需逐项对照数据集 README 与论文后补入配置。未核实数值留空。

## 方程约定

局地坐标 x 东、y 北、z 上；速度单位 m/s。地转风向量表示空气流向，不采用气象学来向角。目标为不可压 Boussinesq LES：

```text
div(u) = 0
D u / Dt = -grad(pi) - div(tau_sgs) + buoyancy * ez
           + (f * (v - Vg), -f * (u - Ug), 0)
D theta / Dt = -div(q_sgs)
buoyancy = g * (theta - theta_ref) / theta_ref
f = 2 * Omega * sin(latitude)
```

pi 为去除背景地转压力梯度后的运动学压力。地转项已包含外加背景压力梯度，求解器中不能重复添加。当前模块只实现驱动力与无摩擦惯性振荡解析解，这些函数不是 LES。

校园草案纬度 31.84° 仅用于估算 f；不能无条件照搬高纬度基准 f。风速、降温率和粗糙度为参考情景，未代表校园实测天气。

## 实施顺序与验收

1. 几何：以黄山路—太湖路—金寨路—宿松路围合区域为研究范围，保留主要建筑及分布特征，按 `geometry.md` 简化细节；核实高度、坐标和日期，建立米制几何及误差清单。计算域在研究范围外设置必要缓冲区。
2. 平坦前驱域：求解器已选定 uDALES，使用其官方前处理和 IBM；验证压力投影、质量守恒、地转平衡和温度输运，配置稳定边界层 SGS 与 MOST，比较速度、位温、通量和边界层高度。uDALES 的 SGS 设置需要单独核实，不能将默认 Vreman 与 SABL 两部分 SFS 模型视为同一方法。
3. 校园域：使用贴体网格或经验证的浸入边界，处理地面、屋顶和立面；决定前驱入流/出流或周期建筑阵列。后者代表重复校园，必须明确解释。
4. 收敛：检查网格敏感性、质量与能量预算、时间步、旋转方向及统计收敛，再分析行人高度风速和尾流。

5 m 网格只是资源规划示例，尚未证明满足建筑 LES。网格要检查街谷宽度、最小建筑尺度及壁面模型适用条件。求解器为 uDALES；硬件和生产运行时间留到真正启动模拟前评估。

JHTDB 用于验证背景边界层，不将平坦域数据当作校园风场。下载接口与认证尚待配置；令牌通过环境变量提供，不写入 Notebook 或 Git。
