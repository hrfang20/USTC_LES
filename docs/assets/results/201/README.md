# 201 结果可视化

取自本地下载的官方 201 算例输出，四个 MPI 分片按坐标拼接为 128³ 网格。最后 fielddump 时刻为 200.21037 s，建筑 STL 最高 22 m。日志末尾显示积分完成约 200.21 s。

- `201_buildings`：官方 STL 三维几何及 solid_c 网格高度。
- `201_wind`：2.5、10.5、25.5 m 水平风速与速度箭头。u/v 从交错面插值到单元中心；利用周期边界拼接。灰色遮罩为 solid_c。
- `201_scalars`：10.5 m 液水位温、总水混合比及 10 m 垂直面速度。灰色为同层单元中心实体遮罩。
- `201_profiles`：直接读取 xytdump 原生统计剖面，展示三个记录时刻；不是最后瞬时场的水平平均。
- `201_surface_energy`：最外层表面温度均值与范围，及面积加权的存储通量；保留原符号，不宣称能量闭合。

风速色标上限为所选切片的 99.5 百分位，标量色标为 0.5–99.5 百分位，以突出空间结构。图中裁剪色标不等于数据截断。

qt 文件单位标签写作 1e-5kg/kg，但固定版本 modfielddump.f90 将 qt0 原值写入，实际约 0.01，与 kg/kg 剖面相符。因此按 kg/kg 转为 g/kg 展示，不按照错误标签再乘 1e-5。

所有图同时提供 PNG 和 PDF。可在项目根目录使用 turbpy 运行 `scripts/visualize_case201.py` 重建。没有使用独立官方参考输出，所以这些图不构成数值验证；200 秒也不能视为充分发展的统计稳态。
