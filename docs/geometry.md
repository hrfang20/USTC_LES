# 东校区建筑识别

定位依据：[中国科大教务处](https://www.teach.ustc.edu.cn/)标注东校区办公地点，地址为合肥市金寨路 96 号。

[Google Maps 搜索入口](https://www.google.com/maps/search/?api=1&query=University+of+Science+and+Technology+of+China+East+Campus+Hefei)用于后续核对。已读取 OSM 建筑和道路矢量并转换为 uDALES STL，未下载或分割 Google Maps 影像。当前没有可用浏览器自动化连接，Google Maps 核对尚未完成。

## 已确定的研究范围

按用户指定，采用**黄山路、太湖路、金寨路、宿松路围合的区域**，不以校园围墙替代该范围。范围内的主要建筑纳入识别，包括非校园建筑。现已选取 OSM 四条道路矢量围合的内侧面；双向车行道形成的窄道路面不纳入研究区域。边界建筑保留完整轮廓，不沿研究边界切成半栋。

闭合经纬度多边形已存为 `data/geometry/study_area.geojson`。`campus_boundary_verified=false` 表示尚未独立核验影像配准；OSM 路网闭合与米制投影已检查。暂定计算域为 1090 × 1350 × 400 m，范围外留 150 m 示例缓冲区；这些是规划参数，周边缓冲区建筑和最终流动边界条件尚待补充。

## 允许的几何简化

初版采用简化平面轮廓加建筑高度挤出的实体，保留：

- 主要建筑的位置、朝向、总体占地和代表性高度，特别是较高建筑。
- 建筑群的排列、疏密与相互间距。
- 主要街谷、楼间通道、庭院与开敞空间。
- 对通道和绕流有明显影响的 L/U 形轮廓及连廊。

可以省略屋顶设备、装饰和小尺度立面细节；较小附属结构根据其对通道遮挡的影响决定取舍。相连且高度接近的建筑部分可以合并，但不能封闭重要通道或填平主要庭院。独立建筑不因距离较近就合并。

原始轮廓存为 `buildings.geojson`，简化米制轮廓存为 `buildings_local.json`，取舍理由存为 `skipped_features.json`。当前采用 0.5 m 保拓扑容差，面积变化超过 2% 则回退；省略小于 25 m²、无名称且高度低于 20 m 的候选结构。数值是初版简化设置，未完成网格敏感性验证。

当前高度为建模情景：9 条用 OSM 楼层数乘以 3.3 m，137 条无楼层或高度资料的记录用 12 m，并标注假设来源及误差；没有已核实的实测高度。这使几何可被 uDALES 读取，不能据此宣称真实高度差异已经还原。首次核对重点是建筑覆盖、布局、通道及高层建筑高度。

## 采集流程

1. 定位四条指定道路，确认交点、道路中心线、北向、影像日期及比例尺，保存来源记录到 `data/raw/`。
2. 标注道路围合边界及范围内建筑；计算域缓冲区内的上游障碍物另行记录。区分屋顶与地面轮廓，检查斜视位移。
3. 逐栋记录高度来源；楼层数估算需带误差。未知高度为 null，不静默填统一值。
4. 区分影像、Google Maps 显示坐标与其他底图坐标，通过控制点检查配准。经核实的 WGS84 几何再转换为局地米制东/北/上坐标。
5. 网格前检查闭合、自交、重叠、孔洞、薄建筑、街谷宽度和最高屋顶。

## GeoJSON 约定

`data/geometry/buildings.geojson` 最终使用经核实的 WGS84 `[lon, lat]`，每栋为 Polygon 或 MultiPolygon，properties 包含：

| 属性 | 含义 |
| --- | --- |
| building_id | 唯一编号 |
| name | 名称，未知为空 |
| height_m | 高度，未知为 null |
| height_source | 高度依据 |
| height_uncertainty_m | 误差，未知为 null |
| footprint_source | 轮廓来源 |
| source_date | 资料日期 |
| coordinate_system_verified | 是否核验坐标 |
| simplification_note | 轮廓简化、细节省略或合并的理由 |

当前集合含 146 条建筑记录。脚本检查多边形有效性、实体并集和官方 STL 拓扑检查；预检查读取实际数量与输入完成状态，实地/影像覆盖核验和高度标定仍待完成。
